# Hi, I'm Jane 👋

I'm an Associate Research Scientist at Columbia University working at the intersection of computational neuroscience and brain-computer interfaces. My research focuses on thalamic circuits, sleep, and biophysical modeling of neuronal systems — and I build BCI pipelines and ML tools to bridge that work with real-world applications.

---

## Projects

### [EEGNet](https://github.com/IVeuromancer/EEGNet) — BCI Motor Imagery Pipeline
End-to-end pipeline for decoding left vs. right arm motor imagery from EEG using an OpenBCI Cyton headset. Trains an EEGNet CNN classifier and uses live predictions to control a pygame game in real time.

`Python` `PyTorch` `BrainFlow` `MNE` `MLflow`

### [SleepScoring](https://github.com/IVeuromancer/SleepScoring) — Automated Sleep Stage Classification
Deep learning pipeline for automated sleep stage scoring from EEG recordings.

`Python` `PyTorch`

### [microCircuit](https://github.com/IVeuromancer/microCircuit) — Thalamocortical Microcircuit Simulation
Biophysical model of a thalamocortical relay (TC) and local interneuron (IN) microcircuit, built with Blue Brain Project tools and simulated in NEURON. Features distance-dependent connectivity, custom ion channel mechanisms, and Poisson spike-train drive.

`Python` `NEURON` `Blue Brain Project` `SONATA`

### [AllOfUs](https://github.com/IVeuromancer/AllOfUs_public) — ML Research on the NIH All of Us Dataset
Research projects built on the All of Us Controlled Tier Dataset (800,000+ participants, individual-level EHR, wearables, genomics, and surveys — access-controlled and pseudonymized). Current work includes an unsupervised ML analysis of opioid-use survey response patterns and a multimodal transformer classifier for opioid use disorder predisposition, combining BioBERT (LoRA fine-tuned) with wearable signal encodings.

`Python` `PyTorch` `Transformers` `PEFT/LoRA` `BigQuery` `HDBSCAN` `UMAP`
