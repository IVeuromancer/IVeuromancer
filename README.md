# Hi, I'm Jane 👋

I'm an Associate Research Scientist at Columbia University working at the intersection of computational neuroscience and brain-computer interfaces. My research focuses on thalamic circuits, sleep, and biophysical modeling of neuronal systems — and I build BCI pipelines and ML tools to bridge that work with real-world applications.

---

## Projects

### [EEGproj](https://github.com/IVeuromancer/EEGproj) — BCI Motor Imagery Pipeline
End-to-end pipeline for decoding left vs. right arm motor imagery from EEG using an OpenBCI Cyton headset. Trains an EEGNet CNN classifier and uses live predictions to control a pygame game in real time.

`Python` `PyTorch` `BrainFlow` `MNE` `MLflow`

### [SleepScoring](https://github.com/IVeuromancer/SleepScoring) — Automated Sleep Stage Classification
Deep learning pipeline for automated sleep stage scoring from EEG recordings.

`Python` `PyTorch`
